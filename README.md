# Minecraft-0.14.3-to-any-version-proxy
Майнкрафт прокси позволяющий игрокам Java 1.8.8-26.3 и Bedrock 26.x подключаться к серверу версии Minecraft PE 0.14.3//Minecraft proxy for authorized players Java 1.8.8-26.3 and Bedrock 26.x connects to the server version Minecraft PE 0.14.3
- Запуск через RUN.bat
- Настройки IP и порта PE 0.14.3 сервера-подключения bridge0_14-server.properties
- Настройки IP и порта входа-выхода Java viaversion.yml
- Настройки IP и порта входа Bedrock plugins\Geyser\config.yml

Используются сторонние плагины
- ViaVersion (https://github.com/ViaVersion/ViaVersion)
- GeyserMC (https://geysermc.org)
